# Ramesh Carpenter Website

A single-screen, retro screen-print inspired carpenter portfolio site.

## Files
- index.html — complete website
- ramesh-carpenter-poster.png — hero artwork

## Customize
Open `index.html` and replace:
- phone number in the Call and WhatsApp links
- "Since 1998" with the actual year
- service descriptions
- any wording you want

Then upload the folder to any static hosting service.
